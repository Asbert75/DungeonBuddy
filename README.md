# DungeonBuddy

DungeonBuddy helps you remember to pick up quest chains that leads into dungeon quests by adding notifications when you reach a level that unlocks the start of a quest chain. 
It also adds a quest tracker that shows quests by dungeon, and shows the chain steps that lead to them, making it easier to see what you can pick up, what you are already working on, and what you have completed.

## Features

- Receive a notification on level-up to remind you when you have quest chains that lead into dungeon quests available
- Browse dungeon quests in a scrollable quest log, organized by dungeon.
- Get extra automatic notifications when entering a zone with relevant available quests to pick up.
- Add directions to a quest source from the quest log or a reminder (Requires TomTom).

## Available commands

| Command | Action |
| --- | --- |
| `/db help` | Show available commands |
| `/db questlog` | Toggle the quest log |
| `/db notification on` | Enable level-up notifications |
| `/db notification off` | Disable level-up notifications |
| `/db settings` | Open settings |
| `/db minimap` | Show or hide the minimap button |
